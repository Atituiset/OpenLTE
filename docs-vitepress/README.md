# 本书介绍

这是一本以 [OpenLTE](https://github.com/mgp25/OpenLTE) 源码为教材的 LTE 无线通信系统学习笔记，
面向**有软件工程背景、刚入行无线通信**的开发者。

OpenLTE 是一套用 C++ 实现的 3GPP LTE 协议栈，包含一个可运行的 FDD eNodeB（基站）、
下行扫频器、IQ 文件录制/生成/扫描工具，以及一套 Octave 离线接收机。
它的代码量不大、没有现代大型项目的层层抽象，非常适合逐行精读——
你能在这一个仓库里看到从比特流编码（ASN.1 PER / NAS TLV）到状态机、
从 USIM 鉴权到 SDR 收发的完整链路。

## 本书结构

- **入门级**：不假设任何无线通信背景。先建立 LTE 网络与协议栈的整体认知，
  把代码跑起来、把包抓到，最后给出一套"怎么读这套代码"的方法论。
- **进阶级**：逐模块深入源码。RRC 的 ASN.1 uPER 编解码、NAS 的 TLV 编码、
  eNodeB 状态机与多线程架构、Milenage/KASME 安全体系、MAC/RLC/PDCP 实现、
  物理层与 SDR 应用——每一篇都落实到具体的文件与函数。

## 阅读建议

1. 入门级按顺序读；进阶级可以按兴趣挑着读，但建议先读「ASN.1 PER 与 RRC 编解码」
   和「NAS 协议与 TLV 编码」这两篇，它们是理解其余一切的钥匙。
2. 所有代码引用都标注了 `文件:行号`，建议打开编辑器对照着读。
3. 文中引用的 3GPP 规范（36.331 / 24.301 / 33.401 / 35.206 等）不必通读，
   遇到具体字段时按章节号查阅即可。

## 构建本书

```bash
cd book
mdbook build    # 输出到 book/book/
mdbook serve    # 本地预览，默认 http://localhost:3000
```

> 本仓库 `docs/` 目录下还有一组同源的阅读笔记（`00_学习路线.md` 起），
> 本书在其基础上重新组织并大幅扩充了源码细节，两者可互相参照。
